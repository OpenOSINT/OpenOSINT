OpenOSINT ships %%TOOL_COUNT%% investigation tools. Each one wraps an external API, a binary or a local computation. They are available through the CLI and REPL, the MCP server and the web UI. The Source, Noise and Needs columns are generated from the code, so they match the version you install.

Noise levels (what they mean): passive tools are on by default; tools that touch the target or are noisy need --allow-active.
